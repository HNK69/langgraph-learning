# LangGraph Learning Foundation

This repository contains my hands-on learning and implementation of the core LangGraph concepts required to build agentic AI systems.

The goal was not just to watch a tutorial, but to understand each building block by implementing it, testing it, and connecting the concepts together.

## What I Learned

### 1. StateGraph

Learned how LangGraph represents an application as a graph of nodes and edges.

- Defined graph state using `TypedDict`
- Used `StateGraph`
- Created nodes and edges
- Used `START` and `END`
- Compiled and invoked graphs

### 2. Conditional Graphs

Learned how a graph can dynamically choose its next step based on the current state.

- Conditional edges
- Routing logic
- Different execution paths
- Ending or continuing execution based on conditions

### 3. Chatbot with LangGraph

Built a basic chatbot using LangGraph and a chat model.

- Message-based state
- `add_messages`
- Chatbot node
- Model invocation
- Maintaining conversation flow

### 4. Tool Calling

Connected external functions/tools to the LLM.

Implemented a stock-price tool and learned:

- Creating tools with `@tool`
- Binding tools to an LLM
- Tool calls generated by the model
- `ToolNode`
- `tools_condition`
- Returning tool results to the model

Basic flow:

```text
User
 ↓
LLM
 ↓
Does the LLM need a tool?
 ├── No → Final Response
 └── Yes
       ↓
    ToolNode
       ↓
    Tool Result
       ↓
      LLM
       ↓
    Final Response
```

### 5. Agentic Tool Loop

Learned how the model can repeatedly reason through tool usage instead of following only one fixed tool call.

The graph can move between:

```text
Chatbot → Tools → Chatbot → Tools → ... → Final Answer
```

This is an important foundation for agentic workflows.

### 6. Memory and Checkpointing

Implemented short-term conversation memory using LangGraph checkpointing.

Used:

- `MemorySaver`
- `thread_id`
- Graph configuration
- Checkpointed state

This allowed the agent to remember information from previous interactions within the same thread.

Important distinction learned:

- **Short-term/thread memory** → conversation state and checkpoints
- **Long-term memory** → persistent information stored separately
- **RAG/external knowledge** → information retrieved from external sources

### 7. LangSmith Observability

Connected the LangGraph application to LangSmith for tracing and observability.

Learned how to:

- Enable LangSmith tracing
- Use `@traceable`
- View graph execution traces
- Inspect LLM calls
- Inspect tool calls
- Follow the complete execution path

A typical trace looked like:

```text
call_graph
   ↓
chatbot
   ↓
LLM
   ↓
tools_condition
   ↓
Tool
   ↓
chatbot
   ↓
LLM
   ↓
Final Response
```

This makes it possible to understand what an agent actually did instead of looking only at its final answer.

### 8. Human-in-the-Loop

Implemented a human approval step using LangGraph interrupts.

Used:

- `interrupt()`
- `Command(resume=...)`
- Checkpointing
- Human approval/rejection

Example workflow:

```text
User
 ↓
Chatbot
 ↓
Tool
 ↓
Potentially sensitive/action-producing operation
 ↓
interrupt()
 ↓
Human Approval
 ├── Yes → Continue
 └── No  → Decline
```

This demonstrated how humans can remain in control of important agent actions.
